# Website development

This is the GitHub Pages version of the ACP family communication guide. Publish from main at repository root. Preserve the working static HTML/CSS/JS architecture and research content boundaries in DESIGN.md.

For new visual work or requested refinements, read available skills `emil-design-eng`, `impeccable`, `taste` (frontmatter: `design-taste-frontend`) and `frontend-design`. Apply the appropriate scope: this is primarily a reading and interactive guide, not a marketing landing page. Preserve Chinese readability, meaningful whitespace, accessible contrast, keyboard operation and reduced motion.

Use the installed Playwright skill to inspect desktop/mobile layouts, test the changed interaction path and capture screenshots in output/playwright/. Keep test artifacts and browser state out of Git. Do not claim publication until pushed and deployed. Figma requires a confirmed account connection and an actual design file when used.
